- [游戏脚本大纲](docs/GAME_SCRIPT_OUTLINE.md) — 国策树、事件脚本、国家设定

## 本地运行

直接用浏览器打开 `index.html`，或使用本地服务器：

```bash
python3 -m http.server 8080
```

访问 http://localhost:8080
