# 元首办公室

钢铁雄心4 第一人称纯文本版网页游戏。

## 设计文档

完整游戏脚本大纲见 [docs/GAME_SCRIPT_OUTLINE.md](docs/GAME_SCRIPT_OUTLINE.md)。

## 本地运行

直接用浏览器打开 `index.html`，或使用本地服务器：

```bash
python3 -m http.server 8080
```

访问 http://localhost:8080
