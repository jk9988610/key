# 《元首办公室》整体设计规划

> 基于 [GAME_SCRIPT_OUTLINE.md](./GAME_SCRIPT_OUTLINE.md) 的扩展设计文档  
> 核心问题：**如何把钢铁雄心4的上帝视角大地图，收束为元首的第一人称体验？**

---

## 一、设计总纲

### 1.1 一句话

玩家不是「国家」，而是**坐在办公桌后面的那个人**。HOI4 里每一次鼠标点击，在这里都对应为：**谁走进办公室、谁打来电话、哪份地图被摊开、哪趟专列在等**。

### 1.2 视角转换公式

```
HOI4 操作              →  元首第一人称等价物
─────────────────────────────────────────────────
点击省份/师团移动      →  听简报 + 批准/否决命令（不亲自画箭头）
国策树点选            →  年度/季度战略方向拍板
外交界面滑动关系      →  接见大使、发电报、里宾特洛甫汇报
生产界面调 slider     →  戈林/施佩尔来要配额，口头定夺
科研选科技            →  科学家进办公室做15分钟汇报
情报间谍网            →  海德里希/卡纳里斯递密封袋
世界紧张度            →  国际新闻简报 + 幕僚情绪反应
暂停/调速             →  不变（玩家仍掌控时间，叙事解释为「日子在过」）
```

### 1.3 三层信息结构

所有系统输出按**元首能感知到的程度**分三层，避免把后台数据直接砸给玩家：

| 层级 | 标签 | 元首感知方式 | 示例 |
|------|------|--------------|------|
| 亲历层 | `[现场]` | 我在场，五感叙事 | 慕尼黑会议室的空气、林茨阳台的风 |
| 转述层 | `[简报]` `[DIP]` `[INT]` | 幕僚口头/书面汇报 | 「里宾特洛甫说英国人会绥靖」 |
| 系统层 | `[SYS]` `[FOC]` | 控制台数值（玩家 meta 视角） | 稳定度 72→68，国策进度 34/70 |

**原则：** 重大决策走亲历层或转述层；日常 tick 走系统层。玩家始终能看控制台，但叙事不依赖它。

## 二、元首的日常：游戏内时间如何流逝

### 2.1 史实作息参考（1936–1939 简化版）

希特勒非常规作息是设计素材，不是折磨玩家的模拟器。我们取其**节奏感**，不做逐小时仿真。

| 时段（柏林时间） | 史实倾向 | 游戏内抽象 |
|------------------|----------|------------|
| 上午 10:00 前 | 起床晚，早餐，阅报 | **晨间阶段**：自动触发 0–1 条「日报/电报」 |
| 上午 10:00–13:00 | 接见、开会、批文件 | **办公阶段**：国策推进、接见、外交事件主窗口 |
| 午后 | 散步、午餐、核心圈闲聊 | **午餐阶段**：随机内阁成员事件、关系微调 |
| 下午–傍晚 | 继续办公或出发去外地 | **决策阶段**：重大决议、是否出远门 |
| 夜间 | 电影、长篇独白、深夜工作 | **夜间阶段**（可选跳过）：情报汇总、次日预告 |

### 2.2 游戏日循环（日结 tick 的叙事包装）

每个游戏日推进时，后台执行 HOI4 式计算，前台按优先级推送：

```
日结 tick
  ├─ [SYS] 国策 +1 日、政治权力 +N、关系衰减
  ├─ [AI]  他国剧本节点检查
  ├─ 生成「今日日程卡」（玩家多数日子无感，快进时只显示系统行）
  └─ 若有事件 → 自动暂停 → 进入场景
```

**日程卡类型（每日最多 1 张，避免刷屏）：**

| 类型 | 频率 | 内容 |
|------|------|------|
| 平淡日 | 60% | 仅 `[SYS]` 行 + 一句环境描写（「今日无大事，柏林下雪」） |
| 公务日 | 25% | 幕僚简报、国策节点、外交电报 |
| 抉择日 | 10% | 需玩家选择的事件/接见/批示 |
| 出行日 | 5% | 触发离京场景（见第三节） |

> 玩家开最高速度时，平淡日合并为每周一条摘要，避免文本洪水。

### 2.3 办公室内的典型活动（可重复的日常模块）

这些模块是「元首主体」体验的核心填充物，让国策等待期不空洞。

#### A. 接见队列（Audience Queue）

每日办公阶段可随机出现 1 位请求者：

| 人物 | 触发条件 | 玩家选项示例 | 系统效果 |
|------|----------|--------------|----------|
| 戈培尔 | 稳定 < 70 | 加宣传力度 / 训斥 / 不见 | 稳定 ±、战争支持度 ± |
| 戈林 | 军备国策中 | 追加空军预算 / 维持 / 削减 | 工厂抽象值、空军倾向 |
| 希姆莱 | 紧张度 > 30% | 加强监控 / 暂不动 | 情报质量、稳定 |
| 里宾特洛甫 | 外交线激活 | 采纳建议 / 自行其是 | 关系 ±、外交事件解锁 |
| 军方代表 | 莱茵兰后 | 批准演习 / 克制 | 紧张度、战争支持度 |
| 科学家 | 科研事件 | 资助项目 A/B | 科技抽象进度 |
| 党内元老 | 随机 | 安抚 / 冷落 | 稳定、政治权力 |

**设计意图：** 把 HOI4 的「_modifier_」「决议」转化为**人际博弈**。

#### B. 地图简报（Map Briefing）

幕僚把地图摊在桌上——这是**大地图的唯一合法入口**。

```
[简报] 凯特尔把东部地图铺开。「元首，波兰边境目前部署了 12 个师，概略在此。」

他用铅笔圈出但泽走廊，没有看我。

[SYS] 东线兵力抽象值: 12 | 波兰边境紧张度: 中
[备忘] 自动写入情报格：「波兰边境 12 师」
```

玩家**永远不能**自由缩放大地图，只能：
- 在简报中要求「详细说明某地」（展开文字描述）
- 在备忘格手写标注
- 出远门时亲历某一地点（见下节）

#### C. 文件批示（Desk Work）

小决策的高频形式，对应 HOI4 的「小决议」：

- 批准/驳回一份人事任命
- 在电报上签字或撕掉
- 选择《人民观察家报》头条导向

耗时短，不打断时间流太久；可设为「不自动暂停」的轻量事件。

#### D. 核心圈午餐（Inner Circle Lunch）

午后随机 2–3 人同桌，触发**非正式外交/派系**事件：

- 戈林与施佩尔争资源 → 玩家选边站
- 鲍曼递小纸条告某人的状
- 闲聊中透露情报（「意大利那边似乎不可靠」）

对应 HOI4 内阁/顾问系统的**人情版**。

## 三、何时离开办公室：出行系统设计

### 3.1 设计原则

| 原则 | 说明 |
|------|------|
| 出行是剧情节点，不是自由探索 | 玩家不能随意点地图旅行 |
| 每次出行有明确目的 | 阅兵、演说、外交会议、验收合并成果 |
| 出行期间办公室事务降频 | 后台 tick 继续，但叙事焦点切换 |
| 史实优先，少量原创 | 1936–1939 可去之地有史可据 |

### 3.2 常驻地点（可切换「办公地点」）

| 地点 | 史实用途 | 游戏功能 | 解锁条件 |
|------|----------|----------|----------|
| **柏林总理府办公室** | 日常政务 | 默认据点；外交、国策、接见 | 开局 |
| **贝希特斯加登（伯格霍夫）** | 度假、密谈、接待外宾 | 外交秘密谈判加成；核心圈事件增多 | 1936 年起可选 |
| **纽伦堡** | 党代会、大型演说 | 稳定度大幅提升；战争支持度 + | 每年 9 月党代会窗口 |
| **慕尼黑** | 啤酒馆、慕尼黑协定 | 巴伐利亚派系事件；慕尼黑会议主场地 | 外交线触发 |

切换地点 = 更换**背景叙事模板** + 少量事件权重修正，不造新 UI。

### 3.3 一次性出行事件（剧情驱动）

| 事件 | 时间 | 场景 | 对应 HOI4 内容 |
|------|------|------|----------------|
| 莱茵兰视察 | 1936.3 | 边境河岸 | 再军事化完成确认 |
| 林茨阳台 | 1938.3 | 奥地利 | 德奥合并终幕 |
| 苏台德入境 | 1938.10 | 捷边境城镇 | 苏台德吞并 |
| 慕尼黑会议 | 1938.9 | 元首行馆 | 慕尼黑协定 |
| 布拉格城外 | 1939.3 | 电台/车队 | 捷克终局（可办公室听广播替代） |
| 但泽边境 | 1939.8 | 边境（预告） | 波兰危机铺垫 |

**流程模板：**

```
[EVT] 出行提议
  戈培尔/里宾特洛甫建议：「林茨的人民在等您。」
  [接受出行] → 切换场景叙事 2–5 段 → 国策/事件结算
  [留在柏林] → 替代文本（办公室听汇报）→ 效果略减（稳定加成减少）
```

给玩家「去或不去」的选择，但**不能无限拖延**史实窗口（倒计时或 AI 剧本强制）。

### 3.4 出行 vs 办公室：事务分配

| 事务类型 | 办公室 | 出行 |
|----------|--------|------|
| 国策推进 | ✓ 主 | ✓ 后台继续 |
| 外交接见 | ✓ | 面对面外交加成 |
| 军事微操 | ✗（仅简报） | ✗（初版不做） |
| 大型演说 | △（广播） | ✓ 现场加成 |
| 情报汇总 | ✓ 夜间 | △ |

## 四、上帝视角 → 元首视角：系统对照表

### 4.1 必须保留（核心 HOI4 味）

| HOI4 系统 | 元首视角实现 | 保留理由 |
|-----------|--------------|----------|
| **时间流逝 + 暂停/调速** | 原样保留 | 节奏是 HOI4 灵魂 |
| **国策树** | 战略方向拍板；里宾特洛甫/鲍曼呈方案 | 德国玩法主轴 |
| **政治权力点** | 「今日决断力」；每日有限决策次数 | 防止无限操作 |
| **世界紧张度** | 国际新闻简报 + 幕僚恐慌度 | 全局压力表 |
| **外交关系** | 大使级往来、电报、会议 | 扩张期核心 |
| **稳定 / 战争支持度** | 国内舆论、党内、民众 | 内政底线 |
| **史实 AI 剧本** | 他国「自行其是」，玩家通过情报得知 | 历史感 |
| **事件链** | 场景化叙事 | 第一人称主载体 |

### 4.2 应当省略（元首不可能/不该亲自做）

| HOI4 系统 | 省略方式 | 理由 |
|-----------|----------|------|
| **省份点击、师团拖拽** | 改为「批准作战计划」总括令（战斗版再做） | 元首不画前线 |
| **每个师的具体编制** | 抽象为「东线兵力：12 师」 | 过细 |
| **工厂建造格子** | 戈林/施佩尔汇报「本月增产 X%」，玩家点头或否决 | 元首不排生产线 |
| **贸易路线、市场** | 删除或合并为「资源：紧张/充足」 | 1936 德国内贸为主 |
| **海军港口、船坞** | 初版删除；后期戈林/雷德尔一句带过 | 初版无海战 |
| **空军联队部署** | 并入军备抽象值 | 同师团 |
| **附庸国微管理** | 总督/保护国「发来贺电」事件流 | 只保留结果 |
| **完整科技树** | 3–5 个「科研项目」事件，选 A/B | 元首拍板方向即可 |
| **间谍网手动布点** | 海德里希汇报「已在布拉格安排人手」 | 操作归幕僚 |
| **议会/选举** | 德国内置为稳定度事件 | 威权政体 |
| **完整国家列表（50+）** | 8 国 + 背景集团 | 见大纲 |

### 4.3 应当考虑（尽量保留 HOI4 深度，但做视角转换）

| HOI4 系统 | 元首视角转换方案 | 优先级 |
|-----------|------------------|--------|
| **国策互斥与前置** | 幕僚争论：「戈林反对先奥后捷」 | 高 |
| **国际反应（保障、宣战威胁）** | 大使递交照会；张伯伦来信 | 高 |
| **将领特质 / 忠诚度** | 布劳希奇/贝克请愿事件；撤换命令 | 中（波兰战前引入） |
| **补给与冬季** | 东线简报一句「补给线过长」 | 低（战争版） |
| **傀儡国建立** | 冯·帕彭出任总督文书签字 | 高（捷克线已有） |
| **阵营（轴心）** | 墨索里尼来电、共同声明 | 中 |
| **轰炸/战略轰炸** | 戈林夸口「伦敦在燃烧」 | 低（战争版） |
| **抵抗运动** | 希姆莱简报盖世太保逮捕人数 | 中 |
| **难民/人口** | 新闻标题式提及，不建人口界面 | 低 |
| **法律/吞并程序** | 办公室签署「合并法案」场景 | 高（奥合并） |
| **公投操纵** | 舒施尼格事件中的幕后选项 | 高 |
| **绥靖判定** | 慕尼黑前英国态度 = 一系列秘密来信 | 高 |
| **国内派系** | 午餐事件、党内倾轧 | 高 |
| **健康/疲劳** | 见 4.4 原创系统 | 中 |

### 4.4 可加入的原创系统（元首为主体）

这些不是 HOI4 原有，但符合第一人称且增强「我是希特勒」的独特性：

| 系统 | 机制 | 与 HOI4 关系 |
|------|------|--------------|
| **决断力（每日）** | 每天 3 点「亲自过问」额度；接见/批示/出行各占 1 | 替代无限点击 |
| **信任圈** | 戈培尔/戈林/希姆莱/里宾特洛甫/鲍曼 五人好感；影响情报偏向 | 类似顾问但有人格 |
| **情绪状态** | 冷静 / 亢奋 / 偏执（隐藏或半显）；影响选项文案与风险 | 无 HOI4 对应，增强角色 |
| **演说准备** | 党代会前选择演讲主题 → 稳定/战争支持不同加成 | 国策的叙事版 |
| **私人备忘** | 玩家备忘格可影响部分事件（「我记下了波兰」→ 后续选项高亮） | meta 玩法 |
| **健康（后期）** | 1943+ 可选；影响出行频率 | 史实向，初版不做 |
| **替身/日程隐瞒** | 彩蛋级事件 | 极低优先级 |

**边界：** 原创系统服务于「元首有限注意力」，不变成恋爱模拟或生活模拟器。

## 五、空间设计：没有大地图的「地图」

### 5.1 信息地理层级

用**命名地点 + 关系**替代经纬度网格：

```
层级 0：世界（仅新闻标题）
  「日本在中国继续推进」

层级 1：战略区（幕僚简报）
  「中欧」「西欧」「东欧」「波罗的海」

层级 2：关键地点（事件场景）
  「维也纳」「苏台德·埃格尔」「但泽走廊」「慕尼黑元首行馆」

层级 3：亲历现场（出行）
  「林茨主广场阳台」「莱茵兰河岸观察哨」
```

### 5.2 「地图」在记事本中的样子

外交格示例：

```
[1938-09-30] 慕尼黑
  英国：绥靖 | 法国：屈服 | 捷：尚未知情
  我承诺：苏台德为最后领土要求 ✓（已记录）

[1938-03-12] 维也纳
  奥地利：已合并
  现场：林茨阳台演说
```

玩家通过**地点时间线**理解天下，而非色块涂满。

### 5.3 距离与时间的叙事换算

| HOI4 概念 | 元首感知 |
|-----------|----------|
| 师团从柏林到波兰边境需 X 天 | 「部队完全展开需两周」——凯特尔口述 |
| 奥地利合并 | 专列 + 阳台一日 |
| 外交照会往返 | 3–7 游戏日 |

## 六、人物与信息链：谁把世界带给元首

### 6.1 内阁信息过滤器

元首听到的永远是**被过滤后的版本**：

| 来源 | 倾向 | 可靠度 | 游戏表现 |
|------|------|--------|----------|
| 里宾特洛甫 | 亲英/亲日乱飘 | 低–中 | 外交建议常过于乐观 |
| 海德里希 | 恐吓式情报 | 中–高 | 国内情报准，国外夸大 |
| 卡纳里斯（若引入） | 反战暗示 | 中 | 秘密渠道事件 |
| 戈培尔 | 宣传胜利 | 低 | 稳定度假象风险 |
| 戈林 | 空军万能 | 低 | 军备浮夸 |
| 凯特尔/OKW | 军事官僚 | 中 | 战报滞后（战争版） |

玩家可选用「交叉核实」消耗决断力，获得 `[INT]` 修正报告。

### 6.2 外国信息如何到达

| 渠道 | 形式 | 延迟 |
|------|------|------|
| 大使递交照会 | 外交事件 | 0–1 日 |
| 电报 | `[DIP]` 行 + 短叙事 | 当日 |
| 广播/报纸 | 背景；戈培尔可曲解 | 0 日 |
| 秘密渠道 | 情报事件 | 1–3 日 |
| 亲自会面 | 出行/柏林接见 | 实时 |

## 七、国策与日常的结合方式

### 7.1 国策不只是点选

每个国策拆为三阶段叙事：

| 阶段 | 叙事 |  gameplay |
|------|------|-----------|
| **启动** | 会议拍板，「今年走奥地利线」 | 消耗政治权力，选分支 |
| **推进中** | 每周 1 条进度简报；随机幕僚阻挠事件 | 日结 tick 进度 +1 |
| **完成** | 出行或签字终幕 | 结算 + 写入国策格 |

### 7.2 初版两条国策线的日常填充示例

## 十一、设计自检清单

开发每个新功能前问：

1. **元首会亲自做这个吗？** 若不会，改为「批准/听取汇报」。
2. **这件事在办公室里合理吗？** 若不合理，是出行还是电报？
3. **能否用一行 `[SYS]` 代替？** 若可以，默认折叠，不写长篇。
4. **是否偏离 HOI4 太远？** 若新增系统，找原游戏里最接近的抽象对应。
5. **是否让元首更像主体？** 至少增加一条只有第一人称才写得出的内心或感官细节。
