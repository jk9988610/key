# 《元首办公室》游戏脚本大纲

> 钢铁雄心4 第一人称纯文本版 · 初版设计文档  
> 默认角色：德意志国总统 阿道夫·希特勒  
> 初版范围：国策树吞并奥地利 → 蚕食捷克斯洛伐克（战斗系统后续版本）

---

## 一、核心概念

### 1.1 一句话定位

玩家以**第一人称**扮演1936年的德国元首，在几乎纯文本的界面中处理内政、外交与扩张。游戏节奏与钢铁雄心4一致——**即时流逝、可调速度、可暂停**；系统状态以**控制台调试风格**呈现；重要信息记入**格子分区记事本**。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 第一人称沉浸 | 所有事件以「我」的视角叙述，强调感官、情绪与决策压力 |
| 极简 UI | 除速度条、暂停钮、少量状态栏外，主体为滚动文本流 |
| 控制台美学 | 国策进度、外交关系、国内稳定等以 `[SYS]`、`[DIP]`、`[INT]` 标签输出 |
| 史实导向 AI | 他国默认按1936–1939史实剧本行动，玩家可扰动但难以完全改写大局 |
| 渐进复杂度 | 初版只做奥地利+捷克线，战斗、海军、空军留待后续 |

### 1.3 技术形态

- 纯前端网页（HTML + CSS + JavaScript），无后端依赖
- 通过 GitHub Pages 部署：`main` 分支合并后自动发布
- 本地状态用 `localStorage` 存档（初版）

│   [SYS] 稳定度 -2 原因: …    │  │    │    │    │    │        │
│   [DIP] 奥地利: 好感 45→42   │  │    │    │    │    │    │        │
│                              │  └────┴────┴────┴────┘        │
│   ── 事件提示 ──              │  格子记事本（点击格子展开详情）  │

### 2.1 时间控制系统（与 HOI4 一致）

| 控件 | 功能 | 对应 HOI4 |
|------|------|-----------|
| ⏸ 暂停 | 冻结游戏时间 | Space / 暂停钮 |
| ▶ 常速 | 1 日/秒（可调） | 速度 1 |
| ▶▶ 快速 | 3 日/秒 | 速度 3 |
| ▶▶▶ 最快 | 10 日/秒 | 速度 5 |

**默认行为：**
- 设置项「出现提示信息时自动暂停」**默认开启**
- 弹出事件/决议/国策完成提示时，时间自动冻结
- 玩家阅读并做出选择后，需**手动点击暂停钮（此时显示为▶）**恢复时间流逝
- 无弹窗时，速度档位正常工作

### 2.2 控制台调试输出规范

```
[SYS]  国内系统：稳定、支持度、工厂、资源
[DIP]  外交：关系值、保障、条约状态
[INT]  情报：他国动向、间谍报告（初版简化）
[FOC]  国策：进度、解锁、完成
[WAR]  战争（后续版本）
[EVT]  事件触发标记
```

示例：
```
[SYS] 1936-03-07 | 稳定度: 68 (-3) | 原因: 莱茵兰再军事化舆论反弹
[DIP] 1936-03-07 | 法国 → 德国 | 关系: -45 | 状态: 互不侵犯条约(活跃)
[FOC] 1936-03-07 | 「重整军备」 进度 34/70 日 | 剩余 36 日
```

### 2.3 格子分区记事本

四格初版分区：

| 格子 | 内容类型 | 自动写入 | 玩家可编辑 |
|------|----------|----------|------------|
| 国策 | 已解锁/进行中/已完成国策摘要 | ✓ | ✗ |
| 外交 | 关键国家关系、条约、承诺 | ✓ | ✗ |
| 情报 | 他国动向简报、间谍报告 | ✓ | ✗ |
| 备忘 | 玩家自由笔记 | ✗ | ✓ |

格子满时，旧条目折叠为「…及更早 N 条」，点击展开时间线。

## 三、世界设定（初版简化）

### 3.1 保留国家（8 个）

| 国家 | 标签 | 初版角色 |
|------|------|----------|
| 德意志国 | GER | 玩家 |
| 奥地利 | AUS | 吞并目标 |
| 捷克斯洛伐克 | CZE | 蚕食目标 |
| 意大利 | ITA | 盟友/协调 |
| 法国 | FRA | 制衡者 |
| 英国 | ENG | 绥靖/施压 |
| 苏联 | SOV | 东方威胁 |
| 波兰 | POL | 缓冲国 |

其余国家合并为「中立集团」或「小国集团」，仅在世界紧张度事件中提及。

### 3.2 史实剧本 AI 默认行为

AI 国家按时间轴执行**预设剧本节点**，玩家行动可提前/推迟/部分改变结果，但核心史实倾向保留：

```
1936-03  德国完成莱茵兰再军事化（开局已发生或即将发生）
1936-07  西班牙内战爆发（背景新闻，不影响初版主线）
1936-11  德日反共产国际协定
1937-07  日本全面侵华（背景）
1938-03  德奥合并窗口期（国策驱动）
1938-09  慕尼黑协定窗口期（国策+事件驱动）
1938-10  苏台德割让
1939-03  捷克剩余领土解决（初版终点）
```

## 四、核心系统（初版）

### 4.1 国内系统（简化）

| 变量 | 范围 | 说明 |
|------|------|------|
| 稳定度 | 0–100 | 过低触发内阁危机事件 |
| 战争支持度 | 0–100 | 扩张行动消耗/需要 |
| 政治权力 | 每日 +1~2 | 国策消耗品（简化为「决策点」） |
| 工厂抽象值 | 整数 | 不细分民用/军用，仅影响国策耗时 |
| 世界紧张度 | 0–100% | 影响他国反应强度 |

### 4.2 外交系统（简化）

- 双边关系值 -100 ~ +100
- 条约类型：互不侵犯、军事同盟、保障独立、附庸
- 无复杂贸易系统；资源用抽象「战略资源充足/紧张」表示

### 4.3 国策系统

- 国策树为**有向无环图**，节点有前置、耗时（游戏日）、成本（政治权力）
- 同一时间只能进行**一个**国策（与 HOI4 早期一致）
- 完成时 `[FOC]` 输出并写入「国策」记事本格子

## 五、国策树大纲（初版）

### 5.1 开局可用（1936年1月）

```
                    ┌─ 四年计划 ─────────────┐
                    │  (提升工厂抽象值)       │
┌─ 重整军备 ────────┤                        ├── 莱茵兰再军事化 ✓(已完成/即将完成)
│  (解锁军事选项)   │                        │
│                   └─ 扩大军备生产 ─────────┘
│
└─ 亲善奥地利 ────── 德奥合并准备 ────── 德奥合并
   (对奥关系+10/日)   (需奥关系>60)      (吞并奥地利)
```

### 5.2 德奥合并线（1938年3月窗口）

| 国策名 | 耗时 | 成本 | 效果 |
|--------|------|------|------|
| 亲善奥地利 | 35日 | 50 | 对奥关系 +2/日；解锁「德奥合并准备」 |
| 德奥合并准备 | 70日 | 100 | 稳定 -5；战争支持度 +5；触发奥地利内部亲德事件 |
| 德奥合并 | 14日 | 50 | 吞并奥地利；世界紧张度 +15%；英法则抗议事件 |

**史实分支：**
- 若玩家在1938年3月前未完成，AI 奥地利可能触发「舒施尼格公投」史实事件，玩家可选择施压或等待
- 法国/英国关系 < -30 时，合并触发「国际抗议」事件链

### 5.3 捷克斯洛伐克蚕食线

```
德奥合并
    │
    ├─ 索取苏台德 ─── 慕尼黑协定 ─── 肢解捷克
    │   (外交施压)     (事件决议)     (获得苏台德)
    │
    └─ 转向布拉格 ─── 保护国成立 ─── 波希米亚和摩拉维亚
        (军事威胁)     (附庸捷克)     (吞并剩余领土)
```

| 国策名 | 耗时 | 成本 | 前置 | 效果 |
|--------|------|------|------|------|
| 索取苏台德 | 28日 | 75 | 德奥合并 | 对捷外交行动；紧张度+8% |
| 慕尼黑协定 | 事件 | — | 索取苏台德 + 英关系>-20 | 会议事件；苏台德割让 |
| 肢解捷克 | 14日 | 50 | 慕尼黑协定 | 获得苏台德地区（抽象领土） |
| 转向布拉格 | 35日 | 100 | 肢解捷克 | 解锁「保护国成立」 |
| 保护国成立 | 21日 | 75 | 转向布拉格 | 捷克成为附庸 |
| 波希米亚和摩拉维亚 | 7日 | 25 | 保护国成立 | 吞并捷克剩余领土；初版结局 |

### 5.4 侧支国策（可选，丰富路线）

| 国策名 | 效果 |
|--------|------|
| 反共产国际条约 | 对苏关系 -15；对日关系 +20；紧张度 +5% |
| 轴心国条约 | 对意关系 +30；意大利更可能支持合并 |
| 绥靖英国 | 对英关系 +15；慕尼黑更容易成功 |
| 挑衅法国 | 对法关系 -20；合并时法国更可能干预（增加稳定惩罚） |

## 六、事件脚本（第一人称叙事）

### 6.1 叙事文风规范

- 使用「我」作主语，现在时或近过去时
- 每段 2–5 句，穿插环境细节（办公室、贝希特斯加登、专列等）
- 系统变化在叙事段后紧跟 `[TAG]` 行
- 重大决策前给 1 句内心独白

### 6.2 开场脚本（1936年1月1日）

```
[EVT] === 游戏开始 ===
[SYS] 日期: 1936-01-01 | 稳定度: 75 | 战争支持度: 30 | 政治权力: 0

我醒来时，窗外柏林的天空是铅灰色的。

新年。帝国的第三年——不，用我们的说法，是民族觉醒后的第三年。
办公桌上的《人民观察家报》头条写着莱茵兰的消息。军队已经在边境演习了，
法国人却还在开会。

[SYS] 世界紧张度: 12%
[DIP] 奥地利: 关系 55 | 状态: 独立
[DIP] 捷克斯洛伐克: 关系 10 | 状态: 独立
[DIP] 法国: 关系 -40 | 状态: 互不侵犯条约(活跃)
[DIP] 英国: 关系 -10 | 状态: 无条约

里宾特洛甫把一份名单放在我桌上。"元首，今年的国策，您想从哪里开始？"

[FOC] 国策树已解锁。请选择首个国策：
  [1] 重整军备
  [2] 亲善奥地利
  [3] 四年计划

── 游戏已自动暂停，请做出选择后点击 ▶ 继续 ──
```

### 6.3 关键事件脚本节点

#### E001 · 莱茵兰再军事化余波（1936年1月，自动触发）

```
法国人在国联抗议了三天。我在听瓦格纳的时候，戈培尔把电报递进来。

"他们除了抗议还会什么？"我说。办公室里的人都笑了，但笑声里有紧绷。

[SYS] 稳定度: 75 → 72 (-3) | 原因: 国际舆论压力
[SYS] 战争支持度: 30 → 35 (+5)
[SYS] 世界紧张度: 12% → 18% (+6%)
[DIP] 法国: 关系 -40 → -48
```

#### E010 · 舒施尼格来访（1938年2月，若未走合并线）

```
奥地利总理来了。他比照片上更矮，手却在发抖。

"德国不会干涉奥地利内政。"我说。我说得很慢，让他每个字都听清。
我也知道他不会信。

[DIP] 奥地利: 关系 55 → 50 (-5)
[INT] 情报: 奥地利国内亲德派活动上升
```

#### E020 · 德奥合并（国策完成）

```
林茨。人群的呼声像海浪。

我站在阳台上。下面的人举着旗帜，嘴里喊着一个名字——不是我的，是"德国"。
一个国家的名字。我属于它，它也属于我。

[FOC] 国策完成: 德奥合并
[SYS] 领土: +奥地利 | 工厂抽象值: +12
[SYS] 世界紧张度: +15%
[DIP] 奥地利: 已吞并
[EVT] 触发后续: 国际抗议事件链
```

#### E030 · 慕尼黑会议（事件决议）

```
张伯伦把雨伞放在门边。那是一把英国伞，在慕尼黑显得格格不入。

他问我："元首，您能保证这是最后的领土要求吗？"

我看着地图上的苏台德。它从来就不是他们的。

"是的，首相先生。"

[DIP] 英国: 关系 -10 → 5 (+15) | 状态: 绥靖
[SYS] 世界紧张度: +10%
[FOC] 解锁: 肢解捷克
```

#### E040 · 终局：布拉格（初版结局）

```
坦克开进布拉格的时候，我在柏林的办公室里听广播。

没有宣战。不需要了。捷克——前捷克——的领土在地图上改了颜色。

冯·帕彭从布拉格发来贺电。我让他当总督。历史会记住这一天，或者不会。
那取决于我们下一步走哪里。

[FOC] === 初版主线完成 ===
[SYS] 捷克领土: 已全部并入
[INT] 波兰东部边境: 德军部署增加（预告后续版本）
[EVT] 游戏继续，但初版内容已体验完毕。感谢游玩。
```

## 七、游戏流程状态机

```
[主菜单]
    ↓ 新游戏（默认：希特勒 / 1936-01-01）
[运行中] ←→ [暂停] ← 事件/提示自动触发
    ↓ 速度档位控制日推进
[日结 tick]
    ├─ 国策进度 +1
    ├─ 政治权力 +N
    ├─ 关系自然衰减/增长
    ├─ 检查 AI 剧本节点
    └─ 检查事件触发条件
    ↓ 有事件？
[事件弹窗] → 玩家选择 → 写入记事本 → 等待手动恢复
    ↓ 初版终点事件
[终局画面] → 可继续沙盒 / 返回主菜单
```
