# 日常事件目录

> 内容实例库，配合 [OVERALL_DESIGN_PLAN.md](./OVERALL_DESIGN_PLAN.md) 使用  
> 机器可读数据：`js/data/daily_events.json`

---

## 一、模板类型

| 模板 ID | 用途 | 自动暂停 | 写入记事本 |
|---------|------|----------|------------|
| `T_QUIET` | 平淡日环境描写 | 否 | 否 |
| `T_AUDIENCE` | 接见队列 | 是 | 视事件 |
| `T_BRIEFING` | 地图/军情简报 | 否（可展开） | 情报格 |
| `T_DESK` | 文件批示 | 是 | 国策/外交格 |
| `T_LUNCH` | 核心圈午餐 | 是 | 情报格 |
| `T_TELEGRAM` | 外交电报 | 否 | 外交格 |
| `T_TRAVEL` | 出行提议 | 是 | 国策格 |

## 三、接见队列（T_AUDIENCE）

### AUD-01 戈培尔 · 稳定度偏低

- **条件**：稳定 < 70
- **叙事**：戈培尔把一叠剪报放在桌上。「元首，国外又在说我们。需要加大宣传吗？」
- **选项**：
  1. 加大宣传力度 → 稳定 +5，战争支持 +3，紧张度 +1
  2. 训斥他夸大其词 → 稳定 +2，信任(戈培尔) -10
  3. 今日不见 → 无变化

### AUD-02 戈林 · 军备诉求

- **条件**：无特殊 / 军备相关国策中权重加倍
- **叙事**：戈林穿着浮夸的制服进来。「元首，空军需要更多配额。英国人的空军在扩编。」
- **选项**：
  1. 追加空军预算 → 工厂抽象 +3，紧张度 +2
  2. 维持现状 → 信任(戈林) -5
  3. 削减其权限 → 稳定 +2，信任(戈林) -15

### AUD-03 希姆莱 · 监控加强

- **条件**：紧张度 > 25
- **叙事**：希姆莱声音很轻。「元首，边境异动增多。盖世太保可以加强监控。」
- **选项**：
  1. 批准 → 稳定 +3，紧张度 -1（国内），写入情报格
  2. 暂不动 → 无变化
  3. 警告他别越权 → 信任(希姆莱) -10，稳定 -1

### AUD-04 里宾特洛甫 · 外交建议

- **条件**：外交线激活或紧张度 > 20
- **叙事**：里宾特洛甫拿着电报。「元首，奥地利那边可以施压了。英国人不会动。」
- **选项**：
  1. 采纳建议 → 对奥关系 +5，对英关系 -3
  2. 自行其是 → 政治权力 +2
  3. 斥其鲁莽 → 对奥关系 -2，信任(里宾特洛甫) -10

### AUD-05 凯特尔 · 边境演习

- **条件**：日期 ≥ 1936-03-01 或 flag: rheinland_done
- **叙事**：凯特尔摊开小地图。「元首，西部边境部队请求演习规模扩大。」
- **选项**：
  1. 批准演习 → 战争支持 +5，紧张度 +4
  2. 克制 → 稳定 +2，战争支持 -2
  3. 亲自过问细节 → 消耗决断力（后续），战争支持 +3

### AUD-06 党内元老 · 抱怨

- **条件**：随机，稳定 < 80
- **叙事**：一位老党员在门外等了一上午。「元首，基层有怨言。物价……」
- **选项**：
  1. 安抚 → 稳定 +4，政治权力 -5
  2. 冷落 → 稳定 -2，政治权力 +3
  3. 交给鲍曼处理 → 信任(鲍曼) +5

### AUD-07 科学家 · 科研项目

- **条件**：随机，低权重
- **叙事**：一位科学家紧张地站在门口。「元首，火箭项目需要拨款……或者喷气机。」
- **选项**：
  1. 资助火箭 → 写入情报格「火箭项目」
  2. 资助喷气机 → 写入情报格「喷气机项目」
  3. 拒绝 → 无变化

## 四、地图简报（T_BRIEFING）

不自动暂停；写入情报格。

### BRF-01 波兰边境

- **条件**：紧张度 > 15 或日期 > 1937
- **叙事**：凯特尔铺开东部地图。「波兰边境目前约 8 个师。但泽走廊标红。」
- **系统**：`[SYS] 东线兵力: 8 | 波兰紧张度: 低`

### BRF-02 莱茵兰

- **条件**：日期 1936-02 ~ 1936-04
- **叙事**：「莱茵兰对岸法军阵地无异常变动。我方边防团已就位。」
- **系统**：紧张度相关

### BRF-03 奥地利

- **条件**：对奥关系 > 50
- **叙事**：里宾特洛甫指维也纳。「舒施尼格政府内部亲德派占三成，还在涨。」

## 五、文件批示（T_DESK）

### DSK-01 人事任命

- **叙事**：鲍曼递来任命书。「是否批准冯·某某出任驻维也纳公使？」
- **选项**：批准 / 搁置 / 驳回

### DSK-02 宣传头条

- **叙事**：戈培尔送来明日头条草案。标题留白等你填。
- **选项**：「德意志觉醒」 / 「和平与秩序」 / 「警告维也纳」

### DSK-03 秘密电报

- **叙事**：里宾特洛甫拟好致伦敦电报。措辞强硬或缓和？
- **选项**：强硬 / 缓和 / 撕掉重拟

## 六、核心圈午餐（T_LUNCH）

### LNC-01 戈林 vs 施佩尔

- **条件**：工厂抽象 > 40
- **叙事**：午餐时戈林和施佩尔几乎同时要同一块肉。桌上安静了。
- **选项**：支持戈林 / 支持施佩尔 / 和稀泥

### LNC-02 鲍曼告状

- **叙事**：鲍曼递纸条：「戈培尔在宣传预算上手脚不干净。」
- **选项**：追查 / 忽略 / 当面问戈培尔

### LNC-03 意大利话题

- **条件**：对意关系 > 0
- **叙事**：有人提起墨索里尼。「领袖最近在埃塞俄比亚惹了麻烦。」
- **选项**：表示支持 / 保持距离 / 提议轴心条约（解锁侧支）

## 九、日程卡抽取权重（日循环）

```
平淡日  60%  → T_QUIET
公务日  25%  → T_TELEGRAM 40% | T_BRIEFING 40% | T_DESK 20%
抉择日  10%  → T_AUDIENCE 70% | T_LUNCH 20% | T_DESK 10%
出行日   5%  → T_TRAVEL（需满足条件）
```

**冲突规则**：每日最多 1 张日程卡；剧情强制事件优先于随机抽取。
